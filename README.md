# KodeTechSolutions Website

A responsive, single-page corporate website starter.

## Included
- Original navy / violet / cyan visual identity
- Services: Website Development, Web Applications, Software Testing & QA Automation
- Responsive mobile navigation
- WhatsApp contact button and project enquiry form
- Email contact link
- No backend required for this starter

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in Chrome, Edge, or Firefox.

## Publish online
You can upload `index.html` to a static hosting service such as GitHub Pages, Netlify, or Vercel. Connect a domain after choosing and purchasing it.
